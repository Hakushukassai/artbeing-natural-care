# 商品別の仮画像

2026-09-10。組み込みの ImageGen を使用し、商品52点とヘナの使い方4工程を個別に新規生成。既存画像・参照画像は使用していません。

- `prompts.json`：全56点の生成指示。商品・素材・構図ごとに独立した指示を使用。
- `products.json`：生成時の商品名とIDの対応。
- `../../src/assets/products/`：商品ごとの掲載用WebP（幅960px）。
- `../../src/assets/guides/`：ヘナの4工程の掲載用WebP（幅1200px）。
- `../../src/data/product-images.ts`：商品名と画像の対応。撮影後はここで各商品の実写へ差し替え可能。

自然光、生成りの布、淡い石や陶器の質感を共通にしています。粉末は粉末、オイルはオイル、クリームはクリームとして表現。容器はラベルのない仮の容器で、実際のパッケージの再現ではありません。毛束・原料・花などはイメージで、実際の染まり方や全配合を保証するものではありません。

ヘナの使い方は、ペーストを溶く・手袋で根元に塗る・キャップで包む・すすぐの4工程。従来の画像は参照せず、説明文から新規生成しています。

元の生成PNGはCodexの生成画像フォルダに保持し、サイトには軽量なWebPを保存。画像の内容を加工せず、サイズと形式のみ最適化しています。
