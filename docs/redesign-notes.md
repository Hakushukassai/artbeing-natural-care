## 方向性

商品を見つけることを最優先に、写真・商品名・余白で構成しています。植物の深緑、明るい白、ヘナの土色、オイルの琥珀色を使用。商品名と操作はゴシック体、ページ見出しは明朝体、ブランド名はセリフ体です。

前回の構成では、英語見出し・キャッチコピー・説明文・矢印・枠線が繰り返され、商品へたどり着くまでに読む量が多くなっていました。今回、一覧の説明を商品ごとの詳細パネルへ移し、装飾的な枠線と重複するコピーを削除しました。FAQの区切り、選択状態、キーボードフォーカスなど、操作に意味のある線や表示は残しています。

トップは短い見出し、同じ大きさの2ブランド、主な4商品、用途リンクに整理。ブランドページは大きな紹介エリアを廃止し、商品一覧を上部に配置しました。共通ナビゲーション、フッター、ガイドなどの見出しも短くしています。

2026年10月8日の決めごと。写真は本物を軸にし、AIで作ったイメージ写真は減らしていきます。公式ストア（maharani.jp）は写真の出どころとしてだけ使い、見た目や並べ方は参考にしません。

## 操作と表示

2026年9月10日、ブランドページを用途の大見出し・商品カテゴリ・商品の順に再構成。全商品一覧は均等なグリッドを維持し、ブランド内では各カテゴリを独立したグリッドに分けています。カテゴリの説明文は追加せず、見出しと余白で区切ります。PCは左側のカテゴリ目次、1050px以下では上部に折り返す目次で各用途へ移動。既存の用途ハッシュは絞り込みではなくページ内の見出しへ接続し、全商品を閲覧できます。ブランド内検索でもカテゴリのまとまりを保ち、該当しないカテゴリだけを省略します。

ブランド・用途・キーワードによる絞り込み、件数の読み上げ、検索結果なしの場合の再操作、商品ごとの詳細パネル、用途を指定するURLハッシュに対応。検索語は全角・半角・ひらがな・カタカナを正規化し、空白で区切った複数語でも絞り込めます。ブランド選択は3つのボタン、用途選択は1つのドロップダウンにまとめています。

スマホのメニューと商品詳細は、既存の Radix UI ベースの Sheet を使用。背景へのフォーカス移動の抑制・Escapeでの閉鎖・スクロールロックを利用し、商品詳細を閉じたときは元の商品ボタンへフォーカスを戻します。

ガイドは4種類のケアを切り替え、各手順の進む・戻る・直接選択に対応。準備チェックにはチェック済みの状態と件数を表示します。

モーションはスクロール時の控えめな出現、写真の拡大、ボタンの押下、詳細パネルの開閉、手順の切り替えに限定。`prefers-reduced-motion` では移動アニメーションを抑えます。スクロール演出はJavaScript無効時にも本文を隠しません。

商品一覧は広い画面で4列、1050px以下で3列、760px以下で2列。トップの主な商品は4列から2列になります。スマホでもブランドを2つ並べ、両方の入口が見えるようにしています。FAQはデスクトップで左側カテゴリー、スマホで折り返し操作。日本語ページ言語・固有タイトル・説明文・キーボードの本文スキップを設定しています。

## 導線の見直し（2026年10月8日）

商品の詳細パネルはページごとに1つだけ置き、開いている商品をURLの `?item=商品ID` で表すようにしました。以前はパネルを開いてもURLが変わらず、スマホで「戻る」を押すと一覧ごと前のページへ戻っていました。今は「戻る」でパネルだけが閉じ、URLを送れば同じ商品が開いた状態で表示されます。ヘナ・インディゴ・香る髪のパネルには、詳細ページと同じ要点（原料・かたち・色の目安・こんなケアに）も表示します。

髪を染める商品（ヘナ3種とハーバルカラー5種）は、一覧の写真の右上に仕上がりの色の丸を付けました。色は `src/data/hair-colors.ts` にまとめ、ガイドの色見本・トップの色の帯・詳細パネルで同じ値を使います。商品タイルの丸に使う色の値は、仮に決めたものです（ハーバルカラー9は商品名から決めました）。

ブランドのページでは、スクロールに合わせて目次の「いま見ている分類」が切り替わります。1050px以下では目次をヘッダーの下に残し、横に送れるようにしました。写真の読み込み中は薄い下地を出し、届いたら写真をふわっと表示します。

トップは、最初の画面（商品の写真と2ブランドの入口）、仕上がりの色から選ぶ、用途から探す、ヘナが届くまで、の順です。以前はAIで作ったイメージ写真を大きく使っていましたが、どのナチュラルコスメにもありそうな絵で、借り物に見えていました。そこで、公式サイトに掲載している本物の写真に切り替えました（2026年10月8日、使用の許可を得て取り込み）。用途の入口は代表の商品の写真にし、内容が重なっていた「主な商品」はここにまとめました。

2026年10月8日の方向。社長からは「畑のイメージは前に出さなくてもよい。より美容を出す」という方向が示されました（参考は公式サイトの「ヘナ白髪染めの選び方」maharani.jp/index_gray.html）。あわせて、トップにはモデル（人）を置かず商品を主役にし、人の写真はほかのページで使う、と決めました。最初の画面に色見本を並べていきなり色で選ばせる形も試しましたが、唐突なのでやめ、最初は写真で見せ、下へ進むと色から選べる順にしています。最初の画面の写真は、ヘナの葉の上に置いたハーバルカラーの袋です（すぐ下の仕上がりの色へ「葉→商品→色」でつながる）。畑の写真は「ヘナが届くまで」の先頭に置いています。モデルの写真（`src/assets/real/hero-model.jpg`）は、ほかのページで使うために残してあります。

## 画像と差し替え

最新のローカル版では、商品52点を公式サイトのパッケージ写真に差し替えました。[公式画像の管理](official-product-images.md) に出典と対応を記録しています。商品以外のイメージ写真は継続使用し、商品写真の注記とは区別しています。以下には以前の生成画像についての履歴も含まれます。

画像は実写の製品写真ではなく、ケア・原料のイメージです。共通フッターと詳細パネルにその旨を表示しています。

新規生成した素材：

| 素材                     | 用途                               | 使用ファイル                                       |
| ------------------------ | ---------------------------------- | -------------------------------------------------- |
| 植物・粉末・オイルの情景 | 私たちについて                     | `src/assets/natural-care-hero-{640,960,1440}.webp` |
| 粉末のハーブシャンプー   | シャンプー系シリーズ・詳細・ガイド | `src/assets/herbal-shampoo-powder-960.webp`        |
| 緑褐色の葉の粉末         | インディゴ・カラーシリーズ         | `src/assets/indigo-leaf-powder-960.webp`           |

元の液体シャンプー、青色の顔料、オレンジ色のヘアカラー粉末という表現は、製品の理解を妨げるため差し替え。生成素材はWebP化しています。トップの大型イメージ写真は情報整理のため廃止しました。生成元PNGは編集用として残してありますが、サイトは軽量なWebPを参照します。

実写へ差し替えるときは、次の箇所を更新してください。

1. ブランド紹介の写真：`src/components/BrandPair.tsx`。
2. 商品ごとの写真：`src/data/product-images.ts` の対応を更新。一覧と詳細パネルへ同時に反映されます。
3. ヘナ・インディゴ・香る髪の詳しい紹介：同じ `productImages` の画像を `src/data/details.ts` でも使用。
4. 操作の写真：`src/data/guides.ts` の `steps.image`。
5. 私たちについて：`src/routes/about.tsx` の画像。

2026年9月10日、52商品それぞれに異なる仮画像と、ヘナの使い方4工程の画像を新規生成しました。元画像は参照していません。[生成指示と保存先](image-generation/README.md) を記録しています。共通フッターと詳細パネルでAI生成の仮画像と明記し、実際のパッケージと区別しています。

商品一覧は縦4:5、商品詳細パネルは画像全体が見える表示です。ブランド写真はPCで横向き、スマホで縦向きになるため、被写体の周囲に余裕のある素材を推奨します。実写へ変更するときは商品ごとの画像を設定し、仮画像の注記も実際の掲載内容に合わせて見直します。
