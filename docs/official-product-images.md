# 公式商品画像

2026年9月10日、ユーザーから公式画像のダウンロード・利用を明示的に許可されたうえで、マハラニ32商品・アタルバ20商品の画像を公式サイトから取得しました。

- 画像：`src/assets/products/official/`。元のJPEGをそのまま保存。画像の生成・色変更・切り抜き・拡大加工は行っていません。
- 出典：`official-product-images.json`。各商品の商品ページ、画像を確認したページ、画像URL、保存先、SHA-256を記録。
- 対応表：`src/data/product-images.ts`。商品名に対応する画像のimportを更新すると、商品一覧・ブランド別一覧・詳細パネル・詳細ページへ反映されます。

容量が複数ある場合は単品の代表的な画像を選択。フェイスクリームRとK、各ヘアカラー、香り別のシャンプー・オイルを区別しています。スキンクリームは公式のLGの写真を代表画像として使用しています。容量や現行パッケージの詳細は公式の商品ページで確認してください。

サイズ調整時に、香る髪・花ブレンドなど11商品の画像を、公式サイトで確認できた高さ500〜600pxの大きな原本へ差し替えました。変更前の画像URLも出典JSONの `previousImageUrl` に記録しています。

画像内の白い余白に左右されず商品自体の高さが揃うよう、`ProductPhoto` で表示範囲を調整しています。縦横比を保ち、一覧では高さ最大240px、詳細では最大280pxに抑えて、低解像度画像の過剰な拡大を避けます。横長の容器は横幅にも上限を設けています。原本のピクセルは変更せず、CSSだけで周囲の余白を整理しています。

`src/data/product-photo-frames.ts` は各画像の商品範囲を記録した表示用データです。画像を差し替えた際は、ローカルのSharp環境で `node scripts/measure-product-photos.mjs` を実行して再計測し、商品が欠けていないか確認してください。

以前生成した商品画像は履歴用として残していますが、商品一覧には使用しません。ヘナの使い方やブランドのイメージ写真は今回の差し替え対象外です。

今回の変更は人による確認用のローカル変更です。GitHubへのプッシュ・公開は行っていません。
